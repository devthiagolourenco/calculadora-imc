## 📌 Sobre o Projeto
Este é um projeto desenvolvido em Python focado na aplicação prática de fundamentos de programação, como entrada e saída de dados (I/O), manipulação de variáveis, operadores matemáticos e controle de fluxo (estruturas condicionais). 

O objetivo do script é receber o peso (em Kg) e a altura do usuário via terminal, realizar o cálculo do Índice de Massa Corporal (IMC) e retornar a classificação detalhada baseada no resultado, indicando as faixas oficiais (desde "Abaixo do peso" até "Obesidade mórbida").

## ⚙️ Funcionalidades
- [x] Captura interativa de peso e altura do usuário via terminal (`input`).
- [x] Conversão de tipos de dados numéricos com ponto flutuante (`float`).
- [x] Cálculo automatizado do IMC utilizando operadores de exponenciação (`**`).
- [x] Arredondamento numérico para duas casas decimais para melhor legibilidade da saída (`round`).
- [x] Exibição de resultados e classificação em categorias de saúde utilizando estruturas condicionais múltiplas (`if`, `elif`, `else`).

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3.x
- **Ambiente:** Execução via Terminal/CLI
- **Bibliotecas:** Nenhuma biblioteca externa necessária (apenas recursos nativos da linguagem).

## 🚀 Como Executar o Projeto

### Pré-requisitos
Antes de começar, você precisará ter o [Python](https://www.python.org/downloads/) instalado na sua máquina.

### Passo a passo
1. Clone este repositório para o seu computador:
```bash
git clone [https://github.com/devthiagolourenco/calculadora-imc.git](https://github.com/devthiagolourenco/calculadora-imc.git)
```

2. Navegue até a pasta do projeto:
```bash
cd calculadora-imc
```

3. Execute o script Python:
```bash
python calculadora_imc.py
```
*(Dica: em alguns sistemas como Linux ou macOS, pode ser necessário usar o comando `python3` ou `python3 calculadora_imc.py`)*
